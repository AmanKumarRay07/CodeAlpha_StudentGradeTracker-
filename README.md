🎓 Student Grade Tracker

Java Programming Internship Project — CodeAlpha

📌 About the Project

Student Grade Tracker is a Java-based console application developed as part of my Java Programming Internship at CodeAlpha.

The application allows users to enter student names and scores, validate the entered scores, and generate a summary report. It also calculates the average score and identifies the highest and lowest scores among all students.

This project helped me apply fundamental Java programming concepts to a practical application.

✨ Features

📝 Enter student names and scores

✅ Validate scores within the allowed range

📊 Calculate the average student score

🏆 Find the highest score

📉 Find the lowest score

📋 Display a summary report of all students

💻 Simple and user-friendly console interface

🛠️ Technologies Used

Programming Language: Java

Input Handling: Scanner Class

Data Storage: Arrays

Control Structures: Loops and Conditional Statements

Concepts: Input Validation and Basic Calculations

⚙️ How It Works

Enter the number of students.

Enter each student's name and score.

The program validates the entered scores.

Student details are stored in arrays.

The application calculates the average, highest, and lowest scores.

A summary report displays all student details and results.

▶️ How to Run the Project

Install the Java Development Kit (JDK).

Clone or download this repository.

Open the project in a Java IDE, such as VS Code or IntelliJ IDEA.

Compile and run StudentGradeTracker.java.

Follow the instructions displayed in the console.
